# Mohamed Karim Belkadi — Portfolio

A cinematic, responsive, dark-only portfolio in `index.html`, with project media in `assets/`. The page uses plain HTML, CSS, and JavaScript, with no build step, framework, paid dependency, external font, or tracking script. Keep the complete `assets/` folder when publishing.

The experience includes a pointer-reactive hero, scroll reveals, a progress line, project filters, keyboard-accessible image galleries, and a full-image lightbox. Motion follows the visitor’s reduced-motion setting. The galleries include 13 FlexTimer screens, 9 fire-detection snapshots, 7 ONEE workflow images, 13 One Fancy app screens, and 3 Blender model images. Private HR and client details are redacted in report screenshots.

## Publish for free

GitHub Pages can host this static portfolio for free from a public repository on GitHub Free. Keep `index.html` at the repository root and preserve the `assets/` folder so the project media loads.

1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and the full `assets/` folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
4. After publishing completes, the site is available at `https://YOUR-USERNAME.github.io`.

A custom domain is optional and may cost money; the `github.io` address is free. [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages)
